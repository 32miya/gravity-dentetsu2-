# 問題ファイルの追加方法

## 1. 仕組み
- ゲームは起動時に `questions/index.json` を読み、そこに書かれたファイルを順番に読み込みます。
- 問題を増やすときは、JSONファイルをこのフォルダに置いて `index.json` にファイル名を1行足すだけです。
- 同じ「問題文＋正解」の組み合わせは自動で除外されます（ファイルをまたいでもOK）。
- 形式が間違っている問題は読み飛ばし、件数がタイトル画面に表示されます。

```json
["base.json", "adult.json", "gourmet_001.json", "showa_001.json"]
```

## 2. 問題ファイルの書き方

```json
{
  "name": "ファイルの説明（自由）",
  "questions": [
    {"g":1, "st":"札幌", "q":"札幌発祥とされるラーメンの味は？", "a":"味噌", "w":["醤油","塩","豚骨"]}
  ]
}
```

| 項目 | 内容 |
|---|---|
| `g` | ジャンル番号（サイコロの出目）1〜6 |
| `st` | 駅名（ゲーム内の駅名と完全一致）。全国共通の問題なら `""` |
| `q` | 問題文 |
| `a` | 正解 |
| `w` | 誤答を3つ |

`[ {...}, {...} ]` のように、配列だけを書いたファイルでも読み込めます。

## 3. 出題のルール
- 手番の人の行き先の駅 → 近くの駅 → 全国共通 の順に優先して出題します。
- 一度出た問題はホストの端末に記録され、そのジャンルの問題が全部出終わるまで再出題されません（ゲームをまたいでも有効）。
- 記録はブラウザに保存されるので、端末やブラウザを変えるとリセットされます。

## 4. AIで問題を量産するときのプロンプト例

```
日本縦断すごろくゲーム用の4択クイズを50問作ってください。
条件：
- ジャンル番号 g=4（昭和平成の思い出）、難易度は「やや難しい」
- 駅は次から選び、その土地にちなんだ問題にする：仙台, 東京, 名古屋, 大阪, 博多
- 事実として確かなものだけ。年号や数字は正確に
- 誤答はもっともらしいが明確に間違いのもの3つ。正解と紛らわしい別解は入れない
- 出力は次のJSON形式のみ：
{"questions":[{"g":4,"st":"東京","q":"問題文","a":"正解","w":["誤答1","誤答2","誤答3"]}]}
```

AIが作った問題には間違いが混ざることがあるので、公開前にざっと確認してください。
